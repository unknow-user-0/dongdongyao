# 洞洞妖 · DongDongYao

> 在任意窗口上「挖一个洞」，看见窗口后面的东西。

洞洞妖是开源小工具「窗口洞洞波」的中文重制版：按住热键，鼠标下面的窗口就被挖出一个形状规整的洞——洞里的内容消失，露出后面的桌面 / 另一个窗口，松开即收。洞跟着鼠标走，可以一层一层往下挖。

![图标](洞洞妖.ico)

## 它能做什么

- **按住出洞，松开收洞** —— 和原作手感一致，不是开关式切换
- **一层一层往下挖** —— 洞开着时按住第二层键，在鼠标下的另一个窗口上再挖一个，可以连着往下
- **五种形状，同一圆心、大小统一** —— 圆形 / 方形 / 心形 / 五星形 / 三角形
- **圆形可切椭圆，方形可选比例** —— 1:1、1:2、2:1、3:4、4:3、9:16、16:9
- **洞洞描边** —— 默认开启，颜色任意取，粗细 1-8 px
- **平滑跟随** —— 默认 16 ms 刷新，可调
- **全中文设置界面** —— 外观 / 快捷键 / 白名单三页，改了立即生效
- **白名单** —— 名单里的程序在挖洞时不会被最小化；「抓取运行中的程序」一键批量加入

## 快速开始

1. 运行 `洞洞妖.exe`，托盘出现图标即可（没有主窗口）
2. 把鼠标放到想挖洞的窗口上，**按住** `` ` ``（Esc 下面那个反引号键）
3. 窗口上出现洞，洞跟着鼠标走；松开就收
4. 洞开着时**按住** `1`，可以在下面那层窗口上再挖一个
5. 右键托盘图标 → 设置

默认热键：挖洞 `` ` `` / 第二层 `1` / 暂停恢复 `F9`，都可以在设置里改。

## 托盘菜单

| 项 | 说明 |
| --- | --- |
| 设置... | 打开设置窗口 |
| 暂停快捷键 | 临时关掉挖洞功能，再点一下恢复 |
| 重新加载 | 改完 `setting.ini` 后重载 |
| 退出 | 保存并退出 |

## 从源码编译

需要 [AutoHotkey 1.1](https://www.autohotkey.com/)（Unicode 32-bit）与 [Ahk2Exe](https://github.com/Ahk2Exe/Ahk2Exe)。

```powershell
Ahk2Exe.exe /in 洞洞妖.ahk /out 洞洞妖.exe `
  /icon 洞洞妖.ico /base "Compiler\Unicode 32-bit.bin" /silent
```

直接双击 `洞洞妖.ahk` 用 AutoHotkey 运行也行，功能完全一样。

> ⚠️ 脚本必须是 **UTF-8 带 BOM**，否则 AHK 会按 GBK 解码，中文提示行会报 `Missing close-quote`。

## 配置文件

同目录下的 `setting.ini`（UTF-8），首次运行自动生成：

```ini
[radius]
radius=300

[options]
rate=16            ; 刷新间隔（毫秒）
shape=circle       ; circle / square / heart / star / triangle
ellipse=0          ; 圆形时是否用椭圆
ratio=4:3          ; 方形 / 椭圆的比例
outline=1          ; 描边开关
outw=2             ; 描边粗细
outcolor=000000    ; 描边颜色 RRGGBB

[hotkeys]
hole=`             ; 挖洞键
second=1           ; 第二层键
pause=F9           ; 暂停 / 恢复键

[winlist]
explorer.exe       ; 白名单
```

改完在托盘点「重新加载」即可，也可以在设置窗口里改（即时生效）。

## 相比原版修掉的几个问题

- **热键会把程序自己一起最小化**：原版只按「鼠标下的那个窗口」排除，而微信 / 豆包 / Electron 类程序的子窗口、弹窗并不等于主窗口，于是主窗口被当成「其他窗口」最小化。现在按 **进程号 + 根窗口（GA_ROOTOWNER）** 双重排除，光标落在子窗口上也不会误伤。
- **图形不再是外接于窗口区域的整块矩形**：区域用 `CreatePolygonRgn` / `CombineRgn` 直接构造，五种形状共用同一圆心、按半径统一缩放（`FitCircle`）。
- **描边颜色正确**：AHK 的 `Gui, Color` 把颜色当 `0xBBGGRR` 解释，所以颜色值在传给 GUI 前做了 RRGGBB → BBGGRR 转换，`FFD400` 就真的是金色。

## 已知限制

- 只支持 Windows；`SetWindowRgn` 对提权（管理员）窗口无效，普通权限的小工具也挖不动管理员窗口——需要两边一致
- 挖洞时目标窗口会被临时置顶，收洞后恢复
